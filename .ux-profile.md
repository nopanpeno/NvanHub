# UI/UX profile — NvanHub

## Aesthetic reference
Gelap dan tegas, gaya editorial (acuan: Marcus Vane, satu halaman). Judul Anton kapital dan besar dipakai sebagai penanda: nama hero, judul bagian, nama proyek, nomor kartu, tanda NvanHub di footer. Bodi Onest, tenang. Pemisah 1px tipis, tanpa bayangan, tanpa kartu melayang. Satu aksen merah-oranye untuk tombol utama, topik aktif, dan nomor kartu. Tidak ada ilustrasi, tidak ada maskot.

Pola halaman: **Marketing home** (komposisi section: hero, marquee, daftar proyek, tentang, footer). Daftar proyek di bagian Proyek adalah pola list dengan filter topik.

## Palet (gelap saja)
- bg `#08080a`: latar halaman (60%)
- surface `#111114`: kartu, daftar kosong, dialog, dan daftar topik (30%). Kartu beda satu langkah dari canvas, plus garis 1px
- surface-2 `#17171b`: hover kartu, tanda NvanHub besar di footer
- fg `#f3f1ea`: teks utama, fokus (17:1 di atas bg)
- muted `#8e8d86`: teks sekunder (6.0:1 di atas bg, 5.7:1 di atas surface)
- line `rgba(243,241,234,.12)` dan line-strong `.26`: garis 1px
- accent `#ff3b1d`: tombol utama (teks gelap di atasnya 5.6:1), nama hero, topik aktif, nomor kartu
- accent-2 `#ff6a3d`: hover tombol utama

Satu aksen saja. Tidak ada warna kedua untuk aksi.

## Typography
- Display: Anton 400 (`assets/fonts/anton-latin-400-normal.woff2`). Dipakai untuk nama hero, judul bagian, peran di hero, nama proyek, nomor kartu, marquee, dan tanda footer. Selalu kapital.
- Bodi: Onest 400, 500, 600 (`assets/fonts/onest-latin-*.woff2`). Tiga bobot saja, tidak ada 700.
- Skala UI: 12 (meta), 14 (label kapital, navigasi, tag, footer), 16 (bodi dan deskripsi kartu), 20 (lead, tagline, Tentang), 24 (tautan footer), 28 (sub-bab). Display: 40 (nama kartu), 52 atau 80 (judul bagian, dengan clamp), dan nama hero lewat `min()` mengikuti lebar layar.
- Line-height: judul dan display 1.1, bodi 1.55. Di bawah 1.1 tidak dipakai.
- Teks panjang maksimal 65ch.
- Teks di bawah 12px tidak dipakai.
- Lisensi font: `assets/fonts/OFL-Anton.txt`, `assets/fonts/OFL-Onest.txt`.

## Banned anti-aesthetics
- Glassmorphism dan `backdrop-filter`
- Gradien pelangi, termasuk di tombol CTA. Header memakai fade satu warna (bg ke transparan), bukan pelangi
- Bayangan blur. Kartu dan panel memakai garis 1px, bukan bayangan
- Neon glow dan border menyala
- Emoji dan ikon pixel
- Maskot atau ilustrasi karakter
- Font dari CDN. Font disimpan di repo
- Animasi yang menggeser layout (width, height, top, left, margin, padding)

## Accessibility target
WCAG 2.1 AA. Teks 4.5:1, teks besar dan border 3:1. Target sentuh 44×44px (tag, tautan, tombol, dropdown, ringkasan cerita). Fokus terlihat: outline 2px `fg` dengan offset 2px. Hover hanya tambahan, di dalam `@media (hover: hover)`, dan tidak ada informasi yang hanya muncul lewat hover. Layout diuji di 375px dan 1280px (tanpa scroll horizontal di halaman).

## Brand tone / microcopy voice
Ramah, santai, sedikit kocak. Tetap jelas dan singkat. Huruf kecil boleh untuk label dekoratif, tidak untuk pesan error atau instruksi penting. CTA selalu kata kerja ("Lihat proyek", "Buka", "Lihat kode", "Baca ceritanya"). Error tidak menyalahkan user dan selalu kasih jalan keluar.

## Motion
- Token durasi: 150ms (`--t-fast`), 200ms (`--t-base`), 300ms (`--t-slow`). Easing: `--ease-out` untuk masuk, `--ease-in` untuk keluar.
- Yang dianimasi: `transform` dan `opacity` saja.
- Judul hero dan peran di hero masuk saat load (kelas `ready` dipasang `js/intro.js`): peran naik per baris 300ms dengan jeda 120ms, nama hero fade dan naik 24px 300ms.
- Kartu masuk saat render dan tiap kali filter berganti: naik 24px sambil muncul, 300ms, jeda 30ms per kartu (sampai 150ms, batas stagger 30ms per item).
- Bagian yang di-scroll (`.reveal`): naik 24px sambil muncul, 300ms, sekali saja. Tanpa JS: langsung tampil.
- Marquee: satu-satunya loop di halaman. 26 detik per putaran, `transform` saja. Pengecualian kecepatan yang disengaja. Mati saat reduced-motion.
- Dropdown topik: keluar 150ms ease-in, masuk 200ms ease-out. Tanpa urutan per opsi.
- Hover kartu dan tombol: ganti warna langsung, tanpa transisi, hanya di `(hover: hover)`.
- `prefers-reduced-motion: reduce`: semua animasi dan loop mati. Konten langsung tampil.
- Konten penting tidak menunggu animasi. Tidak ada pembuka.

## Icon library
Tidak ada ikon di tampilan. Ikon aplikasi (`assets/icons/icon-*.png`) hanya untuk manifest dan apple-touch-icon.

## Stack
HTML, CSS, JS biasa. GitHub Pages. Font disimpan di repo, tanpa CDN (dicek otomatis oleh `scripts/check.mjs`). Tanpa framework, tanpa build. Tidak ada mode terang: halaman gelap saja.
