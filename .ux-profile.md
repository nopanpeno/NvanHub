# UI/UX profile — NvanHub

## Aesthetic reference
Kertas dan tinta, gaya komik yang rapi. Judul Anton kapital dan besar jadi penanda: nama hero, judul bagian, nama proyek, nomor kartu. Bodi Onest, tenang. Panel dan kartu punya border tebal 3px dan bayangan keras yang solid (offset 6px, tanpa blur). Satu aksen merah-oranye, sama dengan logo, untuk tombol utama, nomor kartu, dan garis bawah tautan. Elemen sakuga-vfx dipakai untuk umpan balik aksi: tombol, tab kategori, toast, dan saklar tema di header (`sakuga-toggle`, sekitar 500 KB). Tidak ada maskot atau ilustrasi karakter.

Pola halaman: **Marketing home** (hero, ticker, daftar proyek, tentang, footer). Daftar proyek di bagian Proyek adalah pola list dengan filter kategori (tab).

## Palet
Mode terang adalah default. Mode gelap ikut sistem, atau dipaksa lewat `data-theme="dark"`. Pengguna memilih lewat saklar tema di header. Pilihan disimpan di perangkat (`localStorage`, kunci `nvanhub-theme`) dan dipasang sebelum halaman tampil. Warna didefinisikan sebagai token di `:root` (lihat `css/style.css`).
- paper `#fbf9f4` / gelap `#100e24`: latar halaman (dominan)
- card `#ffffff` / `#1b1838`: kartu, panel hero, dialog
- ink `#1d1a4a` / `#efedff`: teks utama, border, fokus
- ink-2 `#4f4c6b` / `#b4b0d6`: teks sekunder
- lav `#b8b3ff` / `#4d46a6`: hanya untuk bayangan keras, bukan teks
- acc `#ff3b1d`: satu aksen. Teks di atasnya memakai `on-acc` (`#1d1a4a` / `#100e24`)
- footer dan ticker membalik warna lewat token `foot-*` dan `band-*`

Satu aksen saja. Efek sakuga memakai warna bawaannya sendiri (pink dan lavender), dan itu sengaja dibiarkan.

## Typography
- Display: Anton 400 (`assets/fonts/anton-latin-400-normal.woff2`). Untuk nama hero, judul bagian, nama proyek, nomor kartu, dan ticker. Selalu kapital. Tautan footer dan "Kembali ke atas" memakai Onest 600, 16px, huruf renggang, sama dengan Tentang di header.
- Bodi: Onest 400, 500, 600 (`assets/fonts/onest-latin-*.woff2`). Tiga bobot saja, tidak ada 700.
- Skala UI: 14 (label, meta), 16 (bodi, tab, tombol), 20 (lead, tagline), 28 (ticker), 32 (sub-judul Tentang), 40 (nama kartu). Display: clamp 52–88 (judul bagian), clamp 44–104 (headline), dan nama hero lewat `min(23vw, 22rem)`.
- Line-height: display 1 sampai 1.05, bodi 1.55.
- Teks panjang maksimal 62–65ch.
- Teks di bawah 12px tidak dipakai.
- Lisensi font: `assets/fonts/OFL-Anton.txt`, `assets/fonts/OFL-Onest.txt`.

## Banned anti-aesthetics
- Glassmorphism dan `backdrop-filter`
- Gradien pelangi, termasuk di tombol. Header memakai latar datar
- Bayangan blur, neon glow, dan border menyala. Bayangan keras hanya boleh offset solid tanpa blur
- Emoji dan ikon pixel
- Maskot atau ilustrasi karakter
- Font dari CDN. Font disimpan di repo
- Animasi yang menggeser layout (width, height, top, left, margin, padding)
- Loop dekoratif selain dua loop di bagian Motion

## Accessibility target
WCAG 2.1 AA. Teks 4.5:1, teks besar dan border 3:1. Target sentuh 44×44px (tombol, tab, tautan, dan ringkasan cerita). Fokus terlihat: outline 3px `ink` dengan offset 3px. Hover hanya tambahan, di dalam `@media (hover: hover)`, dan tidak ada informasi yang hanya muncul lewat hover. Layout diuji di 375px dan 1280px, tanpa scroll horizontal di halaman. Efek sakuga bukan satu-satunya tanda status: hasil aksi juga muncul sebagai teks (toast, tanda selesai di tombol salin).

## Brand tone / microcopy voice
Profesional, sopan, dan ramah. Bahasa baku, kata ganti "saya" dan "Anda", tanpa slang ("tool" jadi "alat"). Tetap jelas dan singkat. Huruf kecil boleh untuk label dekoratif, tidak untuk pesan error atau instruksi penting. CTA selalu kata kerja ("Lihat proyek", "Buka", "Lihat kode", "Salin tautan", "Baca ceritanya"). Error tidak menyalahkan user dan selalu kasih jalan keluar.

## Motion
- Efek sakuga (hantaman tombol, tanda selesai, geser tab, toast masuk dan keluar) adalah pengecualian yang disengaja. Pegas dan overshoot hanya ada di dalam komponen sakuga. Di luar itu tidak ada bounce.
- Durasi CSS: 150ms (`--t-fast`), 200ms (`--t-base`), 300ms (`--t-slow`). Easing `--ease-out` untuk masuk, `--ease-in` untuk keluar.
- Yang dianimasi di CSS: `transform` dan `opacity` saja.
- Hover kartu: naik 2px lewat `transform`, hanya di `(hover: hover)` dan kalau gerak boleh.
- Dua loop yang disengaja. (1) Ticker berjalan kanan ke kiri, 26 detik per putaran, lewat `transform` saja. Berhenti saat kursor di atasnya (hanya di `(hover: hover)`). Di reduced-motion jadi daftar statis, salinan kedua disembunyikan. (2) Tiga kata hero (Gratis, Tanpa server, Tanpa akun) naik satu per satu, tampil sekitar 3 detik, lalu hilang satu per satu. Jeda kosong sebelum putaran berikutnya di bawah 1 detik (sekitar 4,5 detik per putaran). Lewat `opacity` dan `transform`. Berhenti saat kursor di atasnya. Di reduced-motion ketiganya tampil diam. Di luar itu tidak ada loop.
- `prefers-reduced-motion: reduce`: CSS mematikan transisi dan animasi. Komponen sakuga diam sendiri (mode calm bawaannya). Konten langsung tampil.
- Klik tautan ke bagian (Tentang, Lihat proyek) scroll halus hanya kalau gerak boleh.

## Icon library
Tidak ada ikon di tampilan. Logo `assets/logo.svg` ada di header. Ikon aplikasi (`assets/icons/icon-*.png`) hanya untuk manifest dan apple-touch-icon.

## Stack
HTML, CSS, JS biasa. GitHub Pages. Elemen sakuga-vfx dari `finktheartist/sakuga-vfx` (MIT) ada di `js/sakuga/`, lisensinya ikut di folder itu. Font disimpan di repo, tanpa CDN (dicek otomatis oleh `scripts/check.mjs`). Tanpa framework, tanpa build. Mode terang dan gelap.
