# UI/UX profile — NvanHub

## Aesthetic reference
Pixel-retro playful. Latar terang dengan grid tipis. Judul pixel tebal. Border gelap tebal. Bayangan solid tanpa blur (offset). Tombol pill besar. Ikon pixel kecil. Maskot dino pixel, dipakai di satu tempat per layar.

## Palet (biru)
- ink `#0b1a3a` — teks utama, border, bayangan
- paper `#f4f7ff` — latar halaman
- surface `#ffffff` — kartu
- blue `#1f5eff` — tombol utama, aksen (teks putih di atasnya ±5.1:1)
- blue-deep `#0a2a8c` — hover dan pressed
- sky `#7cc4ff` — dekorasi saja, jangan dipakai untuk teks

Aturan: 60-30-10. Latar 60% paper, kartu 30% surface, biru 10%.

## Typography
- Display: Pixelify Sans, bold. Judul dan label section saja.
- Body: system-ui. Jangan pakai pixel untuk paragraf.
- Dua weight maksimal per layar.

## Banned anti-aesthetics
- Glassmorphism dan backdrop-filter
- Gradien pelangi, termasuk di tombol CTA
- Neon glow dan border menyala
- Emoji sebagai ikon UI
- Ilustrasi pixel lebih dari satu per layar
- Bayangan blur lembut (pakai offset solid)

## Accessibility target
WCAG 2.1 AA. Teks 4.5:1, teks besar dan border 3:1. Target sentuh 44×44px. Fokus terlihat: outline 2px `ink` dengan offset 2px. Hormati `prefers-reduced-motion`: tanpa animasi loop.

## Brand tone / microcopy voice
Ramah, santai, sedikit kocak. Tetap jelas dan singkat. Huruf kecil boleh untuk label dekoratif, tidak untuk pesan error atau instruksi penting. CTA selalu kata kerja. Error tidak menyalahkan user dan selalu kasih jalan keluar.

## Motion
- Hover kartu: naik 2px, bayangan offset mengecil. 120ms, ease-out.
- Pressed: bayangan 0, kembali ke posisi.
- Tanpa animasi infinite. Maskot diam, kecuali reduced-motion off dan dipakai sekali.

## Icon library
Pixel 16×16, satu set saja. Jangan campur dengan set garis (Lucide dihapus dari profile ini). Belum dipasang; buat atau instal saat dibutuhkan.

## Stack
HTML, CSS, JS biasa. GitHub Pages. Tanpa framework.
