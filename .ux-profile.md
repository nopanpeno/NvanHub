# UI/UX profile — NvanHub

## Aesthetic reference
Linear. Gelap, monokrom, border 1px tajam, kepadatan tinggi, gerak minimal.

## Banned anti-aesthetics
- Glassmorphism / backdrop-filter tanpa batas kontras tinggi
- Badge pastel pill untuk metadata biasa
- Gradien dekoratif dan border neon menyala
- Gradien pelangi di tombol CTA
- Ilustrasi kartun di halaman kosong
- Scrollbar bertingkat dan ikon berlebihan di input

## Accessibility target
WCAG 2.1 AA. Kontras 4,5:1 teks biasa, 3:1 teks besar dan border. Target sentuh 44×44px. Fokus terlihat.

## Brand tone / microcopy voice
Utilitarian & minimal. Dingin, presisi, tidak banyak basa-basi.

## Icon library
Lucide. Satu set saja. Jangan campur set lain. Jangan pakai emoji sebagai ikon UI. Belum dipasang; instal saat dibutuhkan.

## Stack
HTML, CSS, JS biasa. GitHub Pages. Tanpa framework.
