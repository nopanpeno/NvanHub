# UI/UX profile — NvanHub

## Aesthetic reference
Pixel-retro playful, mode gelap. Latar gelap dengan grid tipis, titik pixel di tiap persimpangan, dan dua lapis bintang pixel redup (tekstur latar, bukan ilustrasi). Judul pixel tebal. Border terang tegas. Bayangan solid tanpa blur (offset). Tombol pill besar. Ikon pixel kecil. Maskot robot pixel buatan sendiri (cincin holo di atas kepala, biru cyber), dipakai di satu tempat per layar. Animasi banyak, tapi tiap gerak punya alasan.

## Palet (gelap, biru laut)
- bg `#06161f` — latar halaman (60%)
- surface `#0d2633` — kartu (30%)
- ink `#e6f4ff` — teks utama, border, fokus
- muted `#a6c0d1` — teks redup (±8.3:1 di atas surface)
- blue `#0a6bd6` — tombol utama (teks putih di atasnya ±5.1:1)
- blue-hover `#0856ad` — hover tombol (teks putih ±7.1:1)
- blue-pressed `#063a78` — pressed
- link `#6cc4ff` — link dan aksen teks (±8.2:1 di atas surface)
- link-hover `#b3e0ff` — hover link
- sky `#38a8f0` — dekorasi saja, jangan dipakai untuk teks
- shadow `#0b5aa8` — bayangan solid offset, tanpa blur (±2.7:1 di atas bg)

Aturan: 60-30-10. Latar 60% bg, kartu 30% surface, biru 10%.

Maskot (hanya di hero, fill rata tanpa glow): bot `#2b7bff`, bot-dark `#1849d6`, bot-light `#5aa0ff`, cyan `#38cfff` (mata, cincin, aksen), cyan-hi `#e0fcff` (kilau mata), visor = bg. Gambar asli, bukan tiruan karakter lain.

## Typography
- Display: Jersey 10 (Google Fonts), bobot 400 saja, ukuran x1.25 dari skala karena hurufnya kecil. Judul, label section, dan nama kartu saja. Dipilih setelah Pixelify Sans dinilai sulit dibaca (C terbaca O).
- Body: system-ui. Jangan pakai pixel untuk paragraf.
- Dua bobot saja: 400 dan 700. Font display hanya 400; 700 untuk teks bodi (label form, tombol, link).
- Skala: bodi 16, sekunder 14, meta 12px. Judul naik x1.2: h3 19.2, h2 23, h1 clamp 33–57px (lalu x1.25 untuk font display: 24, 29, h1 clamp 41–72px). Line-height judul 1.1–1.2, bodi 1.5.
- Label form pakai font bodi. Pixel di 16px sulit dibaca (C terbaca O).
- Spasi: kelipatan 4 untuk mikro, kelipatan 8 untuk komponen. Teks panjang maksimal 70ch.
- Pola halaman: Portfolio index (nav, hero, filter, grid kartu, tentang, footer). Bukan marketing home.
- Filter topik: dropdown asli (`select`, label "Topik", tiap opsi memuat jumlah proyek), bukan deretan chip. Tag ada 8 (dua per proyek), tapi dropdown tetap dipakai supaya muat saat tag bertambah. Berdiri sendiri, lebar 240px di layar lebar, penuh lebar di HP.

## Banned anti-aesthetics
- Glassmorphism dan backdrop-filter
- Gradien pelangi, termasuk di tombol CTA
- Neon glow dan border menyala
- Emoji sebagai ikon UI
- Ilustrasi pixel lebih dari satu per layar
- Bayangan blur lembut (pakai offset solid)
- Animasi yang menggeser layout (width, height, top, left, margin)
- Animasi tanpa fallback reduced-motion

## Accessibility target
WCAG 2.1 AA. Teks 4.5:1, teks besar dan border 3:1. Target sentuh 44×44px. Fokus terlihat: outline 2px `ink` dengan offset 2px. Hormati `prefers-reduced-motion`: lihat bagian Motion.

## Brand tone / microcopy voice
Ramah, santai, sedikit kocak. Tetap jelas dan singkat. Huruf kecil boleh untuk label dekoratif, tidak untuk pesan error atau instruksi penting. CTA selalu kata kerja. Error tidak menyalahkan user dan selalu kasih jalan keluar.

## Motion
- Library: GSAP 3.12.5 (CDN cdnjs). Pemantau scroll sendiri, tanpa ScrollTrigger (IntersectionObserver dan ScrollTrigger gagal di lompat scroll). Lenis opsional.
- Yang boleh dianimasi: `transform` dan `opacity` saja. Satu pengecualian: `color` teks hero (judul dan lead, kecuali nama di `.accent` yang tetap biru) menuju putih mengikuti scroll, per kata, satu per satu berurutan, lewat variabel `--w` (0 sampai 1) di tiap kata. Berlaku di hero (menurut `scrollY`) dan di bagian Tentang (menurut posisi tiap paragraf di layar; semua putih di dasar halaman). Hanya cat ulang, tidak menggeser layout. Bukan loop, mati saat reduced-motion.
- Durasi 120–600ms. Easing standar (ease-out untuk masuk, ease-in untuk keluar).
- Banyak animasi yang dipakai: reveal kartu saat scroll, stagger masuk grid, teks hero per huruf, hover naik 2px, pressed (bayangan 0, kembali ke posisi), transisi overlay.
- Arah masuk kartu ikut kolom: kiri dari kiri, kanan dari kanan, tengah dari bawah (baris ganjil dari atas), satu kolom bergantian. Geser maksimal 24px (sama dengan gutter) supaya tidak ada scroll horizontal. Judul bagian masuk dari kiri.
- Tautan `#bagian` (tombol Lihat proyek, menu) menggulung lewat tween GSAP 300–600ms, power2.inOut. Berhenti kalau user wheel, sentuh, atau tekan tombol. Hash dan fokus ikut pindah. Skip link tidak ikut. Reduced-motion dan tanpa GSAP: lompat bawaan browser.
- Penanda scroll (bukan loop, hanya bergerak saat scroll): garis progress 4px di tepi atas (`scaleX`) dan grid latar 32px bergeser 25% kecepatan scroll, bintang jauh 10%, bintang dekat 40% (parallax, tanpa loop). Mata maskot menoleh ke kursor selangkah piksel, hanya untuk mouse. Kotak grid di bawah mouse menyala sebentar (fill sky, opacity 0,22 ke 0 dalam 600ms) lalu pudar, sepuluh kotak dipakai bergantian, hanya untuk mouse, bukan loop.
- Animasi loop (maskot, ikon pixel berkedip): satu per layar, boleh hanya saat reduced-motion off. Loop maskot: satu timeline 3.2 detik (cincin naik 1 piksel, segmen cincin menyala searah jarum jam, kedip). Lompat 8px saat disentuh bukan loop. Gerak per langkah piksel, tanpa easing halus.
- Ganti filter: kartu lama pudar dulu (opacity saja, 150ms ease-in), baru diganti kartu baru yang masuk seperti biasa. Filter berganti cepat: hanya yang terakhir dijalankan.
- Tag di kartu = tombol filter (`button`, `aria-pressed`, area sentuh 44px lewat `::after`). Klik tag aktif melepas filter. Fokus kembali ke tag yang sama setelah kartu dibangun ulang. Wilayah `aria-live` mengabarkan jumlah proyek.
- Petunjuk tombol hero: kursor mouse atau fokus keyboard di "Lihat proyek", balon robot memberi tahu fungsinya, hilang saat kursor atau fokus pergi. Satu-satunya balon yang menutup sendiri, karena dipicu hover, bukan timer.
- Petunjuk "Buka website" di kartu: robot yang sama muncul di pojok kanan bawah (salinan gambar, tanpa klik, `aria-hidden`) saat mouse atau fokus keyboard di tombol, hilang saat pergi atau Escape. Kalau robot hero masih terlihat, balon hero yang dipakai. Robot hero sudah di luar layar saat robot pojok muncul, jadi tetap satu robot per layar.
- Cerita kartu terbuka: isi naik 8px sambil muncul (200ms). Tinggi kartu berubah langsung, bukan dianimasi.
- Tombol utama: hover naik 2px dengan bayangan memanjang jadi 5px (bayangan berubah langsung), panah geser 3px (hanya kalau gerak boleh). Ditekan: turun 3px, bayangan 0.
- Cerita kartu: kolom `story` opsional di `projects.json`, tampil lewat `<details>` asli (bukan modal, karena singkat dan tidak merusak apa pun). Tombol "Baca ceritanya" / "Tutup cerita", tinggi 44px, tanpa ikon baru. Kartu tanpa `story` tidak punya tombol. Cerita ditulis pemilik, bukan dikarang Claude.
- Maskot bisa diklik (button asli, Enter dan Space jalan): balon ucapan memuat sapaan acak dari `data/mascot.json` (bukan fun fact). Balon absolut, jadi tidak menggeser layout. Muncul lewat fade opacity, tanpa timer. Menutup lewat Escape atau klik di luar. Pembaca layar mendengar ucapan lewat wilayah `aria-live` terpisah, balonnya `aria-hidden`. Sapaan dijaga pendek (sekitar 90 karakter), supaya muat di samping maskot di layar sempit.
- `prefers-reduced-motion: reduce`: matikan semua loop, scroll-triggered, dan stagger. Sisakan fade opacity ≤150ms atau tampil langsung.
- Tidak ada animasi yang menunda konten penting. Konten harus bisa dibaca tanpa menunggu animasi selesai.

## Icon library
Pixel grid 8×8, dirender 16px, satu set saja. Jangan campur dengan set garis. Set saat ini di `assets/icons/`: arrow, arrow-up, external. Tambah ikon baru hanya saat ada yang memakainya. `arrow` untuk aksi di tab sama, `arrow-up` untuk kembali ke atas, `external` untuk link tab baru.

## Stack
HTML, CSS, JS biasa. GitHub Pages. Library animasi lewat CDN (GSAP). Tanpa framework.
