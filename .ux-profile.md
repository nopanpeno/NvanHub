# UI/UX profile — NvanHub

## Aesthetic reference
Pixel-retro playful, mode gelap. Latar gelap dengan grid tipis. Judul pixel tebal. Border terang tegas. Bayangan solid tanpa blur (offset). Tombol pill besar. Ikon pixel kecil. Maskot robot pixel buatan sendiri (cincin holo di atas kepala, biru cyber), dipakai di satu tempat per layar. Animasi banyak, tapi tiap gerak punya alasan.

## Palet (gelap, biru laut)
- bg `#06161f` — latar halaman (60%)
- surface `#0d2633` — kartu (30%)
- ink `#e6f4ff` — teks utama, border, fokus
- muted `#a6c0d1` — teks redup (±8.3:1 di atas surface)
- blue `#0a6bd6` — tombol utama (teks putih di atasnya ±5.1:1)
- blue-hover `#0856ad` — hover tombol (teks putih ±7.1:1)
- blue-pressed `#063a78` — pressed
- link `#6cc4ff` — link dan aksen teks (±8.2:1 di atas surface)
- link-hover `#b3e0ff` — hover link
- sky `#38a8f0` — dekorasi saja, jangan dipakai untuk teks
- shadow `#0b5aa8` — bayangan solid offset, tanpa blur (±2.7:1 di atas bg)

Aturan: 60-30-10. Latar 60% bg, kartu 30% surface, biru 10%.

Maskot (hanya di hero, fill rata tanpa glow): bot `#2b7bff`, bot-dark `#1849d6`, bot-light `#5aa0ff`, cyan `#38cfff` (mata, cincin, aksen), cyan-hi `#e0fcff` (kilau mata), visor = bg. Gambar asli, bukan tiruan karakter lain.

## Typography
- Display: Pixelify Sans, bold. Judul dan label section saja.
- Body: system-ui. Jangan pakai pixel untuk paragraf.
- Dua bobot saja: 400 dan 700.
- Skala: bodi 16, sekunder 14, meta 12px. Judul naik x1.2: h3 19.2, h2 23, h1 clamp 33–57px. Line-height judul 1.1–1.2, bodi 1.5.
- Label form pakai font bodi. Pixel di 16px sulit dibaca (C terbaca O).
- Spasi: kelipatan 4 untuk mikro, kelipatan 8 untuk komponen. Teks panjang maksimal 70ch.
- Pola halaman: Portfolio index (nav, hero, filter, grid kartu, tentang, footer). Bukan marketing home.

## Banned anti-aesthetics
- Glassmorphism dan backdrop-filter
- Gradien pelangi, termasuk di tombol CTA
- Neon glow dan border menyala
- Emoji sebagai ikon UI
- Ilustrasi pixel lebih dari satu per layar
- Bayangan blur lembut (pakai offset solid)
- Animasi yang menggeser layout (width, height, top, left, margin)
- Animasi tanpa fallback reduced-motion

## Accessibility target
WCAG 2.1 AA. Teks 4.5:1, teks besar dan border 3:1. Target sentuh 44×44px. Fokus terlihat: outline 2px `ink` dengan offset 2px. Hormati `prefers-reduced-motion`: lihat bagian Motion.

## Brand tone / microcopy voice
Ramah, santai, sedikit kocak. Tetap jelas dan singkat. Huruf kecil boleh untuk label dekoratif, tidak untuk pesan error atau instruksi penting. CTA selalu kata kerja. Error tidak menyalahkan user dan selalu kasih jalan keluar.

## Motion
- Library: GSAP 3.12.5 (CDN cdnjs). Pemantau scroll sendiri, tanpa ScrollTrigger (IntersectionObserver dan ScrollTrigger gagal di lompat scroll). Lenis opsional.
- Yang boleh dianimasi: `transform` dan `opacity` saja.
- Durasi 120–600ms. Easing standar (ease-out untuk masuk, ease-in untuk keluar).
- Banyak animasi yang dipakai: reveal kartu saat scroll, stagger masuk grid, teks hero per huruf, hover naik 2px, pressed (bayangan 0, kembali ke posisi), transisi overlay.
- Animasi loop (maskot, ikon pixel berkedip): satu per layar, boleh hanya saat reduced-motion off. Loop maskot: satu timeline 3.2 detik (cincin naik 1 piksel, segmen cincin menyala searah jarum jam, kedip). Lompat 8px saat disentuh bukan loop. Gerak per langkah piksel, tanpa easing halus.
- `prefers-reduced-motion: reduce`: matikan semua loop, scroll-triggered, dan stagger. Sisakan fade opacity ≤150ms atau tampil langsung.
- Tidak ada animasi yang menunda konten penting. Konten harus bisa dibaca tanpa menunggu animasi selesai.

## Icon library
Pixel grid 8×8, dirender 16px, satu set saja. Jangan campur dengan set garis. Set saat ini di `assets/icons/`: arrow, check, close, search, plus, menu, external, heart. `arrow` untuk aksi di tab sama, `external` untuk link tab baru.

## Stack
HTML, CSS, JS biasa. GitHub Pages. Library animasi lewat CDN (GSAP). Tanpa framework.
