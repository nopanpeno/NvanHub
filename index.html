    Tentang

    NvanHub aku bikin sebagai pintu utama buat semua website yang aku buat. Tiap proyek punya alamat sendiri-sendiri, jadi aku butuh satu tempat yang menghubungkan semuanya. Di sini semuanya aku kumpulin jadi satu: tinggal pilih topik, lalu klik.

    Aku suka eksperimen. Ide yang kepikiran langsung dicoba, dan website ini juga jadi tempat aku belajar. Tiap proyek di sini cara aku nyobain hal baru. Kalau jalan, aku bagikan lewat repo, jadi semuanya bisa dibuka, dipelajari, dan dipakai siapa saja.

    Harapanku sederhana: kamu mampir, nemu sesuatu yang berguna atau seru, lalu pulang bawa ide buat dicoba sendiri.

    Fun fact

    Web ini dibuat tanpa framework, cuma HTML, CSS, dan JS biasa, jadi semua proyek di sini jalan tanpa server sendiri. Skor game di NvanPlay disimpan di perangkatmu, bukan di server.
