## UI/UX skills

Taste, a11y, bans, voice, and icon library for this project live in `.ux-profile.md`.
Before UI or microcopy work, read `.ux-profile.md`, then the matching domain skill.
Before creating a new page, name the page pattern. Do not write page markup until it is named.
Layouts must pass `viewports` at 375px and 1280px.
Before finishing UI, run `ux-audit`.
